POWER BI — DAX MEASURES (copy-paste into Power BI Desktop)
=============================================================
Setup: Get Data > Text/CSV > select data/orders_clean.csv > Load.
Name the table "Orders". Then: Modeling tab > New Measure, paste each
block below one at a time (one measure per New Measure click).

-------------------------------------------------------------
Total Revenue =
SUM(Orders[net_amount_usd])

-------------------------------------------------------------
Total Orders =
COUNTROWS(Orders)

-------------------------------------------------------------
Avg Order Value =
DIVIDE([Total Revenue], [Total Orders])

-------------------------------------------------------------
Repeat Customers =
COUNTROWS(
    FILTER(
        SUMMARIZE(Orders, Orders[customer_id], "n_orders", COUNTROWS(Orders)),
        [n_orders] >= 2
    )
)

-------------------------------------------------------------
Total Customers =
DISTINCTCOUNT(Orders[customer_id])

-------------------------------------------------------------
Repeat Rate % =
DIVIDE([Repeat Customers], [Total Customers])
-- Format this one as Percentage in the Format pane.

-------------------------------------------------------------
Pct Late % =
DIVIDE(
    CALCULATE(COUNTROWS(Orders), Orders[delivery_status] = "Delivered Late"),
    COUNTROWS(Orders)
)
-- Format as Percentage. Duplicate this pattern for Cancelled / Returned:

Pct Cancelled % =
DIVIDE(
    CALCULATE(COUNTROWS(Orders), Orders[delivery_status] = "Cancelled"),
    COUNTROWS(Orders)
)

Pct Returned % =
DIVIDE(
    CALCULATE(COUNTROWS(Orders), Orders[delivery_status] = "Returned"),
    COUNTROWS(Orders)
)

-------------------------------------------------------------
Avg Delivery Days =
AVERAGE(Orders[delivery_days])

-------------------------------------------------------------
Revenue (Excl. Cancelled) =
CALCULATE([Total Revenue], Orders[delivery_status] <> "Cancelled")
-- Use this measure (not Total Revenue) on the country/category/trend
-- charts, to match the SQL project's logic of excluding cancelled orders.

-------------------------------------------------------------
Pct of Total Revenue =
DIVIDE([Revenue (Excl. Cancelled)], CALCULATE([Revenue (Excl. Cancelled)], ALL(Orders)))
-- Use on the category bar chart to show each category's % share, same
-- as the "pct_of_total" column in the SQL output.

-------------------------------------------------------------
Pct of Orders (Payment) =
DIVIDE(COUNTROWS(Orders), CALCULATE(COUNTROWS(Orders), ALL(Orders[payment_method])))
-- Use on the payment-method chart, with payment_method on the axis.

=============================================================
VISUALS TO BUILD (map to the dashboard you already have):
  - 4 Card visuals: Total Revenue, Total Orders, Avg Order Value, Repeat Rate %
  - Line chart: order_month (axis) x Revenue (Excl. Cancelled) (values)
  - Clustered column: country (axis) x Revenue (Excl. Cancelled) (values)
  - Bar chart: category (axis) x Revenue (Excl. Cancelled) (values), sorted desc
  - Table: country, Total Orders, Avg Delivery Days, Pct Late %, Pct Cancelled %, Pct Returned %
  - Bar chart: payment_method (axis) x Pct of Orders (Payment) (values)
  - Slicers: country, order_month
